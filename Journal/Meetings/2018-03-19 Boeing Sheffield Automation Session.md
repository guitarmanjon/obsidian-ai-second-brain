## Key Discussion Points

- [[Aiden Lockwood]]: short projects with [[Boeing]] Sheffield (BS) around automation as preliminary work; has fed into BS on IT infrastructure requirements (five 9s availability).
- 3 areas of interest identified from a BS IT / IMG workshop:
	1. [[Siemens]] Mindsphere connectivity of Foers machine tools - targeted live April 2018. All machines need [[Siemens]] controllers; current Foers machines are not all [[Siemens]] (WFL and Starrag will be; Doosan not currently 840D, discussions ongoing on conversion). Project includes analytics work.
	2. Smart fixture data collection demonstrator - start as and when BS advise. BS working with Metlase, IMG supporting Metlase in developing smart fixtures with sensors implanted in the fixture. Fixture needs sign-off by BS before work continues (no date yet); would monitor fixture health via sensor data. Not started yet, IPT not defined - needs Design and Machining group involvement. Unknown whether Metlase will provision sensor hardware.
	3. Cutting tool data capture and transfer - start as and when BS advise. Aim to seamlessly integrate tool data capture into manufacturing systems, capturing tooling data during setting and delivering it to the machine via RFID. Possible outsourcing of tool setting, but data management remains part of this project ([[PK]] query on outsourcing).
- Budget: automation-related work above £5k cap-ex has its own pot of money (£250k); people and machines budget (£300k).
- Still many unknowns around what BS actually want - robot loading? Twin spindle? Other automation (tool delivery, part delivery, etc.)?
- [[On-Machine Inspection|OMI]] work must deliver recommendations on a fully connected factory; inspection by exception; using Mindsphere for pure OEE-type data seen as wasteful - could support smart manufacturing instead.
