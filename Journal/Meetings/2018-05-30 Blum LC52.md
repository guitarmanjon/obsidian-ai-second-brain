- Data output from the LC52 can be used to build a tool wear data set (e.g. "after X number of cuts, wear is Y").

- A touch screen PC has been added to the machine to support data collection.
- Question raised on whether the PC can be used for other services - answer: it can, but Blum prefer this isn't done.
