## Key Discussion Points

> [!note] What was talked about?
> Capture the substance - not a transcript, but the important points, context, and nuance that you'd want to recall later.

- Issue 1 - probing along the tool axis: no calibration possible with a single ruby probe (not a star probe) because you can't probe both sides of the ruby, which calibration requires. WFL said this isn't necessary anyway since the probe is used for relational, not absolute, measurements - the switching characteristic is the same at both measurement points (referenced video: "38 - DP7 WFL Demoteil M40 mpg1" in the WFL manual folder).
- With a star probe, one lateral stylus can be calibrated using the current WFL calibration cycles: a calibration ring/artefact of known size is needed at 90° to the stylus, and PRCALIB is called normally with the ring gauge axes as inputs. Stylus 1 can be calibrated in Y and Z; stylus 2 in X and Y (at B0).
- Issue 2 - standard feature measurement isn't catered for by the WFL cycles. [[Hartwig]] (Speigner) explained WFL's philosophy is not to prescribe how users inspect a feature - tools let the user measure any feature any way they choose. Example given: bore/boss - the WFL manual implies two-point diameter measurement, which is error-prone. Hartwig described how PROBE, PRCALC, and PROBE2P cycles could be combined to build a better measurement cycle (illustrated in a diagram on the original page).
- Issue 3 - stylus offsets, tied to centreline calculations which require them. WFL's proposed solution: spin the probe so the same point on the ruby contacts the surface each time (e.g. measure Y+ on a bore, spin the probe 180°, then measure Y- with the same contact point). This works but isn't ideal - a single 180° spin doesn't add much time, but it adds up significantly across many measurements, and effectively negates the need for omni-directional probes (everything could be done with a uni-directional probe).
- [[Martin Drew]] (KYAL machine tools) suggested a day or two of training from a WFL probing expert, with AMRC's questions/issues/problems (diagrams, descriptions) sent ahead so the trainer can prepare. A meeting is needed at AMRC first to identify what input is wanted from WFL.
