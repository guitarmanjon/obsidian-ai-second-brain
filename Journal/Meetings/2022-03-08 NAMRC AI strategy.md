## Purpose

- Review Datta's vision, plan and strategy for building [[Nuclear AMRC|NAMRC]] [[AI]]/[[Machine Learning|ML]] capability.

## Key Discussion Points

- [[Dattatraya Parle]] ("Datta") started as [[Nuclear AMRC|NAMRC]]'s Tech Lead for [[AI]]/[[Machine Learning|ML]] at the end of November. His strategy (shared 3rd March 2022) is built around four pillars:
  1. Infrastructure - establishing compute across local systems, HPC and cloud, with clarity on which infrastructure suits which project.
  2. Tools and technologies - enabling/running [[AI]]/[[Machine Learning|ML]]/DL tooling, currently focused on open source with exploration of commercial toolsets via partnerships.
  3. Capabilities - building [[AI]]/[[Machine Learning|ML]]/DL models on existing data from past projects (textual, numeric, image and mixed data, including large/complex datasets) until commercial engagements land.
  4. Skill and resource building - team building as customer interactions grow, with in-house training planned as the team expands.
  - Long-term vision: build reusable model libraries / data libraries for [[Nuclear AMRC|NAMRC]] [[AI]]/[[Machine Learning|ML]].
  - Currently working largely alone, with support from the digital team.
- Intros between attendees.
- [[Rab]] presented using older [[AI]] slides which still cover much of current capability.
  - [[Richard Lanyon-Hogg]] proposing a knowledge capture project to DASA.
  - Idea: a manufacturing terminology corpus, using a login "re-captcha"-style approach (e.g. choosing traffic lights) to crowd-source training data for [[Machine Learning|ML]] models.
- Data sets and sufficiently powerful computation are [[Dattatraya Parle]]'s current biggest challenges.
