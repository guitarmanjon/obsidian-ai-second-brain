## Key Discussion Points

> [!note] What was talked about?
> Capture the substance - not a transcript, but the important points, context, and nuance that you'd want to recall later.

- These sessions were intended to become regular, every ~2 months, half a day.
- IDC funding finishes after 2018 (last intake) - board funding for IDC students.
- Milestones: today's session (IDC); <2 weeks - ABG SoWs for Nov 2017 funding; November 2017 - Catapult funding from April 2018; March 2018 - prep for the next round of ABG project funding from April 2018; November 2018 - Catapult from April 2019.
- [[PC]] gave an IDC overview - main link is to Mech Eng; question of whether it could also link to Comp Sci, ACSE etc.
- EngD ideas/proposals - Gears/PM&C:
  - Adaptive machining of complex forms - could include developing inspection methods to gather enough data points to reliably update tool offsets (measure cuts); how many data points are needed, is a contact scanning system essential; if on-machine inspection (OMI) is to replace some CMM-type inspection, data needs to be collectable, traceable and correlated back to CMM data; could also extend to machinability of material - using sensor data to adjust feedrate/spindle speed as material properties change.
  - Advanced on-machine inspection - bringing NDT techniques onto the machine platform to remove later manufacturing stages (instant feedback on machining parameters); deliberate on-machine work hardening (single setup, avoiding repeated machine-treat cycles); re-centring WCS to avoid forging inclusions; on-machine surface finish evaluation feeding into adaptive machining.
  - Through-life part monitoring and process feedback - comprehensive shop-floor data collection covering both part and machine tool data; not yet clear exactly what data needs to be collected; would include early manufacture parameters (forging, treatment), shop-floor data, and possibly in-service data; identifying which data matters (e.g. tracing a later-manufacture failure back to an earlier process/material data point) and how the number of data streams may need to change as relationships are identified.
  - Aerofoils/PM&C - quantity of components that data is captured for in through-life monitoring; potential case-study components (fan blade, turbine blade); question of whether a common system (e.g. Polyworks, MeasureLink) is essential, given some already feed into Polyworks -> MeasureLink; measure cuts for aerofoils; link to the Metrology Hub.
