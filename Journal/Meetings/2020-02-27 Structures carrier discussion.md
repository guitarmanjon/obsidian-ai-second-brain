- [[Mike Locking]], [[JS]]

## Purpose

- Exploratory discussion on fixture-sensing concepts for the Structures carrier project, particularly around linking fixture data with machining/sensor data.

## Key Discussion Points

- Floating fixture and damping discussed.
- Schunk fixture:
  - Vero-S - a pneumatic clamping system comprising individual units that clamp onto pegs attached to the part; each unit can clamp/unclamp as needed to hold or release the part, allowing control of part distortion.
  - The latest version might include sensing capability - could this data be aligned with machining and sensor data?
  - Understanding the movement of pins when released could reveal something interesting about part distortion.
- Basic idea: put sensors in the fixture and link fixture sensor data to machining data to build a complete dataset.
- MetLase sensor units mentioned as a possible option.
