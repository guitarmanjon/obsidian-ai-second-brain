## Key Discussion Points

- OWA roadmap is available on SharpCloud with open access to AMRC - described as very comprehensive.
- Fit4OWA referenced.
- Boeing is very interested in hole certification using process monitoring methods.
  - Geometry is important - currently done with a plug gauge.
  - Hole quality is just as important - currently checked by taking the stack apart and inspecting; ideally this would be done via sensor data instead.
- Funding challenge: £500k Catapult funding to be match-funded by partner DG funds.
  - Already interested: BAE (~£80k), Boeing (~£80k), Spirit (~£80k, no DG funds).
  - ASSystem UK / Expleo mentioned.
- Siemens Edge:
  - Deploy to a Titan robot for edge analytics and qualification.
  - High rate data capture.
  - Edge computing seen as key, given the need for near-real-time evaluation of hole quality.
- [[PC]] gave an overview of PhD student work on force feedback:
  - Using Kistler data for analysis of drilling processes.
  - Lots of data in a dyno data stream.
  - Question raised: can any of this data be made redundant by sensor data or power data? Resolution is important.
