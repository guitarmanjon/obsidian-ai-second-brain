## Key Discussion Points

> [!note] What was talked about?
> Capture the substance - not a transcript, but the important points, context, and nuance that you'd want to recall later.

- AV&R indicates when a defect has been found but does not classify it. This project aims to increase trust in the AI model - understanding how robust it is, if/when/how it fails, and empowering the AI system.
- Work so far has looked at scales vs. secondary grains - how many examples are needed to train the AI model? Slithers noted as low incidence with obvious features.
- Plan to move away from Power AI eventually; two separate models being developed - one for slithers (RX-Y images), one for scales/secondary grains (X images). Power AI currently used for proof of concept.
- AV&R asked to separate images into a folder containing only defective images; they initially wanted payment but this is now resolved. They will modify the recipe to create the separate folder and have indicated where the data identifying defective images is, so the team could filter themselves - expected within the next 2 weeks.
- Plan going forward: use production blades from R-R. Can historic data be used as training data for future models? I2C2 analysis to determine how many samples are needed. Scope is now to categorise defects, not classify them.
- Bounding box identified as a critical point.
- Noted that AV&R appear to already be doing a lot of what this project is trying to achieve.
