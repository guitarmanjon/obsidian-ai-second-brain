## Key Discussion Points

- AIC subsidiary context.
- Accuracy of robot cells discussed - GEBE2 project.
- EMMAtools (part of AIC): detects and records chatter; uses two single-axis accelerometers at the front and rear spindle bearings; also collects machine tool NC data. Described as "pro looking" software.
- [[Spindle]] health monitoring: a 2-minute check on the spindle signature.
- Fischer spindles can have the system embedded as an optional extra.
- Encoder positioning captured - real machine position vs programmed position, correlated to vibration/NC/feed/speed data.
- Website has a good demo video.
- The tool has been used to identify tools and programs that are bad for spindle/[[Machine Health Monitoring|machine health]].
- "EU TEC" noted, likely referring to Europe Technologies.
