## Key Discussion Points

(Note: the source text has some image caption fragments - e.g. "BAE" / "Warton Vi..." - interleaved with the notes; these appear to be labels for embedded photos rather than a genuine second text column, and have been omitted below as noise.)

- Aim of the A4D Tempest work is to reduce assembly time via improved assembly tolerances, one-way assembly, etc.; A4D will feed into future Tempest work. A "Meccano"-type build (no shims, no complex tooling) is desired.
- BAE want to learn from AMRC's approach to making these parts; BAE colleagues with prior AMRC experience recommended this team talk to AMRC.
- Six different part numbers, 9 components total; 3 (stem) part numbers are hand/opposite pairs (-1 and -2). [[Lee Parkinson]] has a spreadsheet with part images and size/billet details.
- Actions carried over from [[PK]]'s previous visit:
  - Metrology: capacity is fine, but capability to manipulate models and extract GD&T data is behind where it needs to be (team used to working from 2D drawings).
  - [[PK]] has raised the project (ADG4423) and Windchill.
  - NDA cover: a separate NDA is needed - [[PK]] has checked and it's in motion.
  - Coolant: currently using Houghtons 795B, being phased out - can change if needed. [[DP]] believes a 3000-series coolant is used in the Ecospeed, as 795B has previously caused issues with aluminium. [[Lee Parkinson]] noted part accuracy is key, so whichever machine/coolant/tooling combination delivers will be used.
- [[Lee Parkinson]]'s notes from Dave (Dawson): CAM strategy - NX is used at BAE; Structures at AMRC uses CATIA, with NX capability in-house.
- NX vs CATIA: [[PK]] may need to look at what BAE want and can support - could look at parts done in CATIA, NX, and PowerMill. Transfer of knowledge/capability/skills/method is key for BAE.
- [[Bob Naylor]] noted this project uses "shared services" machine tools at BAE (equipment shared between teams, "who shouts loudest owns the equipment") - hence asking AMRC to make the parts.
- Order of build is not an issue for BAE to provide.
- Data transfer: Windchill already set up; BAE need to confirm data transfer through Windchill is acceptable.
- Run-through of [[PK]]'s draft SoW: design-for-manufacture feedback to BAE (including the design team) on features that can't be machined or are unnecessarily difficult/expensive to machine.
- AMRC to buy material; BAE to provide grade, treatment, etc.
- First step once BAE share parts is to determine the approach per part - some may be fast-tracked to a less rigorous method, others through full rigorous review/design-for-manufacture.
- Data capture requirements: currently cycle (tape) time; AMRC could do better using STC/Ecospeed (in-cut time, spindle run time, air time, etc.). Target machines from [[PK]]: Ecospeed, NMV8000, Hermle C52 (possibly).
- BAE staff will make themselves available for required meetings at AMRC. Key project milestones include on-machine time and major milestones.
- Agreed to remove "Tempest" from the SoW and use "A4D" instead.
