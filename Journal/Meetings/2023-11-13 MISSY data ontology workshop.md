## Attendees

- AMRC: [[JS]], [[TR]], [[LL]], [[JE]], [[RS]]
- [[Rolls-Royce|R-R]] ([[Rolls-Royce]]): [[Jonathan Butters]], [[Neil Tatman]] (left at 14:30)

## Purpose

- Workshop with [[Rolls-Royce]] to progress the [[MISSY]] project's data ontology, building on the existing data dictionary.

## Key Discussion Points

- Data Dictionary recap: Excel-based so it's accessible to more of the team; uses Bronze-Silver-Gold levels, consistent with [[Databricks]] conventions.
- [[Jonathan Butters]] (JB) commented on graph databases and triple-stores: probably don't need a graph DB; the data dictionary itself is essential; other views are needed too, e.g. material data.
- [[Neil Tatman]] (NT) wanted to catch up on [[MISSY]] and find out more about DoE (question raised over whether this was the right session for DoE). He has been developing a document defining what [[Rolls-Royce|R-R]] would like to see from AxRCs, including use cases such as predictive maintenance. NT is concerned that [[MISSY]] isn't looking at these use cases, and asked whether schemas exist for the DoEs, KPIs, and sensor definition lists.
- [[JS]] asked whether the discussion could continue without an answer to NT's question; [[Jonathan Butters]] confirmed yes, the plan is to translate the Excel data dictionary contents into a conceptual map.
- Ontologies discussion: ISO 15926 proposed as a possible starting point.

## Decisions

- Agreed (per [[Jonathan Butters]]) to proceed with translating the Excel data dictionary contents into a conceptual map, even without a firm answer yet to NT's question on DoE schemas.
