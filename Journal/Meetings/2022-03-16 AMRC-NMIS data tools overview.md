## Key Discussion Points

- [[JS]] gave an overview of the AMRC Data Cloud.
- [[Andy Sherlock]] discussed getting NMIS data scientists into local companies for consultancy, working with in-house data types.
- NMIS tools overview:
  - Run.ai - Kubernetes cluster on-prem, GPU-based, GPUs assigned per person/team, used to build/train/test/deploy and run Jupyter notebooks.
  - Filament.so - runs on AWS, Colab-notebook-like, similar to Datalore.
- NMIS has data from previously forged parts which could be shipped to AMRC for future work.
- Strathclyde PURE flagged as a possible source of open-source datasets, along with a Zenodo record for radial forging sensor data at the AFRC testbed.
