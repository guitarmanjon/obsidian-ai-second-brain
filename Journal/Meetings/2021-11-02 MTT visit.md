## Key Discussion Points

> [!note] What was talked about?
> Capture the substance - not a transcript, but the important points, context, and nuance that you'd want to recall later.

- AMRC gave an overview of the need for LF data to be sent to a database instead of the current CSV file method; [[Steve McVey]] agreed the CSV method isn't sustainable.
- This work aligns with other projects at MTT trying to do similar things with sensors and data.
- Discussed triggering of data capture - whether M codes could be used to start/stop capture, and whether generic M codes exist that work across all controllers/machine tools. [[JS]] showed how SINUMERIK Edge triggering is achieved.
- [[HL]]'s EPSRC work aligns closely with ongoing work at MTT. [[Steve McVey]] described MTT's test rig - a 3-axis machine tool with all covers removed, allowing bearings to be accessed easily so elements of the machine can have accelerated wear applied (e.g. removing grease from bearings, adding dirt).
- Opportunity raised to collaborate or use MTT's machine for EPSRC trials.
- [[HL]] gave an overview of HF/NI-captured sensor issues - some sensors not working, some giving poor response, some poorly chosen. Strain gauges have no response, and the accelerometer in the front spindle bearing is not responding.
