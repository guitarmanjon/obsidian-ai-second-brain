## Key Takeaways

- **Part 1 - Intro and [[AI]] definition (10 + 10 mins)**: state the workshop purpose (understand [[AI]] work/talent per group, build a cross-AMRC map, find collaboration opportunities with [[University of Sheffield|UoS]]); group leads complete a profile sheet beforehand; one idea per sticky note, use sharpies, keep to time. Then have attendees define, as a group, what counts as "[[AI]]-related research" (technologies, activities, subject areas) on a large sticky note - refer back to this definition throughout.
- **Part 2 - Past and present projects (60 mins)**: use two sticky-note colours for "past" vs "present". 15 mins: brainstorm one project per sticky note (title + project number if known). 40 mins deep dive (~5 min/project) capturing: manufacturing application (quality inspection, process control, predictive maintenance, etc.); [[AI]] techniques used (why [[AI]], core intelligence engine, what the algorithm does, training data type/volume/structure, data engineering effort); key people/collaborators (technical lead, domain expert, internal/external collaborators); value (if known); key outcomes (past: status/impact, savings, still in use, deployment status, follow-on work; current: milestones, biggest challenge, blockers/needs). Consider grouping projects by similar application or technique.
- **Part 3 - Future aspirations (30 mins)**: set up wall zones for Research/projects, Capabilities, Collaborators. 15-20 mins: one aspiration per sticky note in the relevant zone - future [[AI]] research ideas (most significant change to manufacturing if successful, headline business case e.g. % cost/time saving, what it looks like in 2 years); [[AI]] capabilities wished for (skills, hardware, recruitment needs, barriers to starting, data/infrastructure hurdles, "blank cheque" tool/platform); desired collaborators (which AMRC groups need to be on board, organisational policies that could slow things down, companies to work with). 10 mins: group and prioritise related aspirations, note which are already being pursued, funding sources being considered, and blockers. Final prioritisation question: if only one idea could be funded, which and why - does it align with AMRC priorities?
